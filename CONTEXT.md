# Контекст работы

## Страница `/sports/football`

- Блок `Спортивные объекты` переименован в `Спортивные мероприятия`.
- Убрана подпись `Где заниматься`.
- Добавлена кнопка `Все мероприятия` на одной линии с заголовком блока, прижатая к правому краю секции.

## Карточки спортивных мероприятий

- Убраны лишние подписи и бейджи:
  - `2 услуги`;
  - `Спортивный объект`;
  - `Спортивный объект для регулярных занятий`;
  - расписание объекта.
- Правая часть карточки перестроена:
  - сверху название мероприятия;
  - ниже дата и время;
  - ниже стоимость посещения;
  - затем название объекта и адрес.
- Названия мероприятий сделаны разными для каждого вида спорта.
- Названия команд в мероприятиях взяты в кавычки.
- Вместо двух цен выводится одна строка `Стоимость посещения: ...`; часть мероприятий бесплатные.
- Кнопка `Записаться` заменена на кнопку `Подробнее`, прижатую к правому краю карточки.

## Блок `Тренера`

- Ниже блока `Спортивные мероприятия` добавлен блок `Тренера`.
- Добавлены карточки тренеров по текущему виду спорта.
- В карточке тренера есть:
  - фото;
  - фамилия, имя, отчество;
  - звание;
  - адрес и время присутствия;
  - кнопка `Подробнее`.
- Сгенерированы и добавлены изображения тренеров:
  - `public/images/coaches/coach-1.png`;
  - `public/images/coaches/coach-2.png`;
  - `public/images/coaches/coach-3.png`;
  - `public/images/coaches/coach-4.png`.
- Для отображения в карточках заменены мужские ФИО на женские там, где используются женские фото:
  - `Воробьев Михаил Сергеевич` -> `Воробьева Мария Сергеевна`;
  - `Соколов Алексей Андреевич` -> `Соколова Алина Андреевна`.

## Блок `Трансляции`

- Ниже блока `Тренера` добавлен блок `Трансляции`.
- Добавлены карточки трансляций, соответствующие выбранному виду спорта.
- В карточке трансляции есть:
  - превью фрагмента соревнования;
  - полупрозрачная размытая кнопка воспроизведения поверх превью;
